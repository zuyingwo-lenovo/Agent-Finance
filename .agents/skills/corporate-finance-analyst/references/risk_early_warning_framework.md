# リスク分析 & 早期警戒指標フレームワーク (Risk & Early Warning Framework)

企業の破綻・業績急減・資金ショート・減損リスクを定性・定量の両面から検知し、財務波及経路を論理的に整理するための実務フレームワークです。

---

## 1. 財務危機・経営悪化の早期警戒指標 (Early Warning Indicators: EWIs)

以下のシグナルが複数合致した場合、レポートの「F. リスク分析」において重要度・発生確率を格上げし、注視点として提起します。

| 早期警戒指標 (EWI) | 判定基準 / 警戒ライン | 背景にある実態と財務リスク |
|---|---|---|
| **営業利益 vs 営業CFの逆転** | $\text{営業CF} < \text{営業利益}$ が2期以上継続 | 売掛金の焦げ付き、在庫の異常積み上がり、または売上過大計上（粉飾・前倒し計上）の疑い。 |
| **オーバートレーディング (Overtrading)** | 売上増収率 $> +20\%$ かつ $\text{CCC}$ が大幅長期化 | 急成長に伴う運転資金需要が自己資金創出力（営業CF）を上回り、急激な借入依存または黒字倒産危機。 |
| **在庫滞留と粗利率の同時悪化** | $\text{DIO (在庫日数)}$ 増加 かつ $\text{GPM (粗利率)}$ 低下 | 売れ残り商品の滞留と、それを処分するための値引き販売（投げ売り）。将来の棚卸資産評価損（減損）の前兆。 |
| **売掛金回収遅延** | $\text{DSO}$ が前年比 $+15$日以上 または 業界平均を大きく超過 | 取引先の信用悪化、無理な押し込み販売、または回収条件緩和による見かけの売上維持。 |
| **インタレスト・カバレッジの急落** | $\text{ICR} < 3.0$倍（警戒）、$< 1.0$倍（危険） | 金利上昇局面で利払いが営業利益を食いつぶす状態。元本返済余力の枯渇。 |
| **純負債倍率の急拡大** | $\text{Net Debt / EBITDA} > 3.5〜4.0$倍 | 創出キャッシュフローに対する負債過多。格下げリスク、社債スプレッド拡大、新規借入枠の縮小。 |
| **有形固定資産の過小投資** | $\text{Capex} < \text{減価償却費}$ が長期継続 | 生産設備の老朽化を放置し、短期的なキャッシュフローを捻出している状態。将来の競争力喪失。 |
| **のれんの自己資本侵食** | $\text{のれん} / \text{純資産} > 50\%$ | 買収先事業の成長鈍化時に巨額減損が発生し、債務超過に転落する潜在的リスク。 |

## 2. アルトマン Zスコア (Altman Z-Score) 分析

製造業・非製造業の倒産確率を客観的に判定する多変量判別モデル。

### (1) 上場製造業向けオリジナルモデル (Original Z-Score)
$$Z = 1.2 X_1 + 1.4 X_2 + 3.3 X_3 + 0.6 X_4 + 0.999 X_5$$
- $X_1 = \text{正味運転資本 (NWC)} / \text{総資産}$（流動性尺度）
- $X_2 = \text{利益剰余金} / \text{総資産}$（累積収益性尺度）
- $X_3 = \text{EBIT (利払前税引前利益)} / \text{総資産}$（資産生産性尺度）
- $X_4 = \text{株式時価総額} / \text{総負債}$（資本構造・財務レバレッジ尺度）
- $X_5 = \text{売上高} / \text{総資産}$（総資産回転率尺度）

**判定基準**:
- $Z > 2.99$: **安全圏 (Safe Zone)** - 健全な財務基盤
- $1.81 \le Z \le 2.99$: **グレーゾーン (Grey Zone)** - 業績動向の継続監視が必要
- $Z < 1.81$: **危険圏 (Distress Zone)** - 2年以内の倒産リスクが極めて高い

### (2) 非製造業・新興市場向け改訂モデル (Altman Z'-Score)
$$Z' = 6.56 X_1 + 3.26 X_2 + 6.72 X_3 + 1.05 X_4$$
- ※ $X_4 = \text{純資産簿価} / \text{総負債}$
- 判定: $Z' > 2.60$ (安全), $1.10 \le Z' \le 2.60$ (グレー), $Z' < 1.10$ (危険)

## 3. 財務コベナンツ (Financial Covenants) 評価マトリクス

銀行借入契約や社債発行要項に付帯する代表的な財務制限条項と、その抵触リスクの検証手順:

| コベナンツ種別 | 一般的な制限水準 | 検証方法 | 抵触時の影響 |
|---|---|---|---|
| **純資産維持条項** | 決算期の純資産を直前事業年度末の75%（または特定金額）以上に維持。 | 最新B/S純資産額と過年度純資産推移を照合。 | 期限の利益喪失 (Acceleration)。銀行団による一括繰上返済請求。 |
| **経常利益 / 営業利益維持条項** | 2期連続の経常損失（または営業損失）を出さないこと。 | 損益計算書の過去2期の損益推移および当期予想を照合。 | 金利ペナルティ（上乗せ金利）または担保差し入れ要請。 |
| **レバレッジ制限条項** | Net Debt / EBITDAを4.0倍以下、または自己資本比率をXX%以上に維持。 | デット指標とEBITDAの最新推移を計算。 | 新規コミットメントラインの凍結、配当支払の制限。 |
| **配当制限条項** | 配当総額が当期純利益または分配可能額の一定割合を超えないこと。 | 株主還元方針とフリーキャッシュフロー水準を比較。 | 増配の停止要請、資本政策の制約。 |

## 4. 業界別固有リスク・マトリクス (Sector-Specific Risk Profiles)

| 業界・セクター | 最重要財務リスク | 注視すべきKPI / 開示項目 |
|---|---|---|
| **自動車・重工業** | 巨額設備投資の回収遅延、EV移行に伴う研究開発費・減損負担、リコール引当金、為替感応度。 | Capex/売上高、研究開発費比率、製品保証引当金残高、為替1円あたりの損益感応度。 |
| **半導体・ハイテク** | シリコンサイクルのボラティリティ、製造装置の急激な減価償却費負担、先端プロセス開発競争。 | 在庫回転日数、有形固定資産除却・減損損失、設備投資キャッシュアウト、受注残高。 |
| **小売・EC・外食** | 店舗閉鎖に伴う違約金・原状回復引当金（減損）、人件費・光熱費高騰、過剰在庫滞留。 | 既存店売上高前年比、棚卸資産回転日数、減損損失（店舗単位のCGU）、リース負債残高。 |
| **SaaS・サブスクリプション** | 顧客獲得コスト（CAC）高騰、チャーンレート（解約率）上昇によるLTV毀損、株式報酬による希薄化。 | ARR成長率、Net Retention Rate (NRR)、Rule of 40 (売上成長率 + FCFマージン)、SBC費用。 |
| **医薬品・バイオ** | パイプラインの開発中止（臨床試験失敗）、特許切れ（パテントクリフ）、開発費の無形資産減損。 | R&D費用対売上高、主力品目特許満了年、無形資産残高、承認フェーズの進捗。 |
