# 企業財務調査・分析 AIスキルパッケージ (Corporate Finance Analyst Skill)

公開情報（有価証券報告書、SEC 10-K/10-Q、決算短信、IR説明会資料等）を厳格な根拠とし、企業の財務状況、収益性、成長性、資本効率、資金繰り、事業リスク、および競合ベンチマークを調査・分析・整理するための実務的なAIスキルパッケージです。

---

## 1. パッケージ概要 (Overview)

本パッケージは、経営企画・事業企画・競合調査・取引先評価・投資検討などの実務において、シニア金融アナリスト水準の財務レポートをAIが安定的・再現的に生成できるように設計されています。

### 主な特徴
- **一次情報最優先**: EDINET、TDnet、SEC EDGAR等の開示書類を直接参照し、出典・注記を明示。
- **再現性の高い指標計算**: デュポン分解（3段階/5段階）、ROIC、現金循環日数（CCC）、Net Debt/EBITDAなどの厳密な計算体系。
- **決定論的計算スクリプト**: Python標準ライブラリのみで動作する `scripts/financial_calc.py` を同梱。
- **標準化されたレポートフォーマット**: エグゼクティブサマリーから財務三表、指標推移、競合比較、リスク早期警戒指標、出典一覧（A〜H）まで網羅。
- **中立性の徹底**: 売買推奨や投資助言を排除し、事実・分析・仮説を分離した意思決定支援レポートを提供。

## 3. 使い方 (How to Use)

### (1) Antigravity IDE での呼び出し
本リポジトリ内の `.agents/skills/corporate-finance-analyst/` は Antigravity の Workspace Skill として自動認識されます。  
チャット上で企業分析を依頼するか、[user_intake_template.md](user_intake_template.md) を貼り付けることで、エージェントが自動的に当スキルを起動して調査を開始します。

### (2) 指標計算スクリプトの直接実行
同梱の `financial_calc.py` を使用して、手元の財務データから即座にデュポン分解や時系列推移Markdownテーブルを生成できます。

```bash
# デモ実行（トヨタ自動車の実績データによるシミュレーション）
python scripts/financial_calc.py --demo

# カスタムJSONファイルからの計算
python scripts/financial_calc.py --file path/to/financials.json
```

## 4. 分析範囲と標準出力フォーマット (Standard Output)

レポートは以下の8部構成で標準化されています:

1. **A. エグゼクティブサマリー**: 3〜5行結論、ポジティブTop 3、懸念要因Top 3、経営注視点、信頼度評価
2. **B. 企業・事業構造概要**: 本社、上場市場、セグメント別構成、収益ドライバー、顧客・サプライヤー集中度
3. **C. 財務ハイライト（3〜5年）**: P&L、B/S、CFの時系列推移表（YoY、CAGR付）
4. **D. 主要財務指標一覧**: 成長性、収益性、資本効率（デュポン分解）、安全性、CF創出、CCC、株主還元
5. **E. 競合・ベンチマーク比較**: 競合2〜5社とのマージン・資本効率・投資強度・マルチプル比較
6. **F. リスク分析 & 早期警戒指標**: 財務波及経路、重要度、発生確率、早期警戒指標（EWI）、確認資料
7. **G. 分析上の限界・追加確認事項**: 未開示項目、会計基準差の制約、次回決算時の確認論点
8. **H. 出典一覧**: 資料名、発行主体、公開日、公式URL、参照頁の一覧

## 5. 設計原則と品質基準 (Quality Assurance)

- **事実と解釈の峻別**: 「会社開示の確定数値（事実）」「指標から導かれる客観的評価（分析）」「将来の見通し・リスクシナリオ（仮説）」を明別。
- **会計基準差異の明記**: IFRS（リース資産負債の全額オンバランス、のれん非償却）、US GAAP、日本基準（のれん定期償却、特別損益）の会計ルール差を考慮。
- **中立的表現**: 投資判断（買い・売り）の断定を排し、意思決定者が客観的にリスクとリターンを秤にかけられる情報構成を提供。
